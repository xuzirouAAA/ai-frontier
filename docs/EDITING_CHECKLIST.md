# 人工编辑 Checklist

所有发布文章在部署前必须完成以下检查。每篇文章编辑时间约 20-40 分钟。

## 一、事实核查

- [ ] 产品版本号、发布日期准确（如 GPT-4 发布时间、Claude 版本号）
- [ ] 公司/人物名称拼写正确
- [ ] 统计数据有来源引用（论文、官方博客、可信新闻）
- [ ] 标注了 `[待核实]` 的地方已完成验证或修正
- [ ] 价格、融资额等数字已核实

## 二、内容质量

- [ ] 正文 ≥ 1500 字，有实质分析而非泛泛而谈
- [ ] 文章有独特观点或个人编辑视角（不只是新闻摘要）
- [ ] 逻辑连贯，段落之间有过渡
- [ ] 列表项有价值，不是凑数
- [ ] 引用块引用的是有分量的话，而非鸡汤

## 三、去除 AI 痕迹

- [ ] 删除 AI 常用开场白（"在……的今天"、"值得注意的是"）
- [ ] 替换 AI 常用总结句式（"总之/综上所述/不可否认"）
- [ ] 检查是否有前后矛盾的观点
- [ ] 删除过度使用"令人惊叹/至关重要/意义深远"等空泛修饰
- [ ] 标记了 `[待补充实测数据]` 的地方已补充或删除该标记

## 四、可读性优化

- [ ] 小标题有信息量，不是"核心分析"、"总结"这种空标题
- [ ] 段落长度适中（2-4 行为宜）
- [ ] 专业术语有上下文解释（面向非专业读者）
- [ ] 中文流畅自然，无翻译腔

## 五、SEO 优化

- [ ] title 含核心关键词， ≤ 50 字
- [ ] description 含关键词，吸引点击， ≤ 160 字
- [ ] tags 覆盖核心话题， 3-5 个
- [ ] 内容中自然出现关键词（不堆砌）
- [ ] coverImage 与文章内容相关

## 六、补充素材（如需）

- [ ] 补充产品截图或对比图（保存到 public/images/）
- [ ] 补充实际测试数据或使用体验
- [ ] 添加外部链接到原始来源
- [ ] 更新 affiliateProducts 为相关产品

## 七、最终检查

- [ ] `editorStatus` 设为 `published`
- [ ] `lastVerified` 设为当天日期（YYYY-MM-DD）
- [ ] `editorNote` 填写简要编辑说明（如"经人工编辑审核，核心事实已核实"）
- [ ] `readingTime` 基于实际字数计算
- [ ] 本地运行 `npm run build` 无错误
- [ ] 预览文章页样式正常

## 发布流程

1. 编辑文章 JSON 文件（`data/articles/{slug}.json`）
2. 完成上述 checklist
3. 运行 `npx tsx scripts/publish-reviewed.ts` 提交并推送
4. 确认 Vercel 部署成功
